# caixin（财新数据库）裁决 — 留

- **评估对象**: `docs/research/kimi-sources/caixin.md`（2026-09-13 describe dump）
- **裁决**: **留** — 687 接口/22 类中有约 200 个（8 个整类）在免费侧与本项目其他 kimi 源（wind/gildata，乃至 ifind）均无等价物，且独有面是"整类别"而非零星 API；wind 式的前缀白名单在 caixin 上机械不可行（687 个接口全部走单一 `caixin_api_call` API 名 + `caixin_call_name` 参数，`SOURCE_ALLOWED_API_PREFIXES` 按 api 名过滤根本落不了子）。
- **本裁决做了 live 验证**（9 次 `caixin_api_search` 元数据探测 + 1 次 `caixin_api_call` 免费接口实调，积分消耗 0；详见文末证据）。

## 0. 关键事实（影响裁决的前置发现）

1. **两工具元架构**：caixin 只有 `caixin_api_search`（接口检索，返回参数/示例/前20字段/积分/是否免费）+ `caixin_api_call`（统一调用入口，`caixin_call_name` 必须精确匹配检索返回的中文名）两个工具，687 个接口全部藏在后面。多数接口单次固定返回 5 条、`pageNum` 翻页；score 多为 20 积分，少数 0（免费）。
2. **live 实调成功**：免费接口"上市公司产业链主题代码表-通用"（score=0）实调返回 121 条产业链主题（氟化工/航运/风电/小米汽车/模拟芯片…），含境内外企业 1月/3月/1年涨跌幅与主题描述，CSV 正常落地 —— 数据真实、口径可用。
3. **已知集成缺口（不改裁决）**：`caixin_api_search` 的真实结果落在响应 assistant 通道的嵌套 `is_success` 键里，本仓 `KimiProvider._extract_call_result` 取 user 通道优先 → 经 `kimi_datasource call` 走 search 时 `data_preview` 只剩空信封 `{"data_preview": ""}`。数据调用（`caixin_api_call`）不受影响（user 通道即完整载荷）。修法：`_extract_call_result` 增加对 assistant 通道嵌套 `is_success` 键的回退解析（后续任务）。
4. **保留成本 = 0**：与 wind 同理，`tools/kimi.py` 只暴露通用 `kimi_datasource call source=caixin`，无 dispatch 改动；不调用不耗积分。

## 2. 定量结论

687 接口分类账（按类别整块归档，含部分重叠类的折算）：

| 档位 | 约计 | 占比 | 明细 |
|---|---|---|---|
| 免费等质/近似可替 | **~410** | ~60% | 股票 155、公募基金 41、财务 33、宏观 33、期货 22、科创 22、货币 16、指数 6、机构库大半、行业大半、研报/处罚重叠部分 |
| 不可替（真独有） | **~200** | **~30%** | 保险库 51、人物库 20、环保 20、私募 15、债券发行人 14、舆情 10、专利 8、银行监管指标部分、公用/清单依附 18、产业全景 5（**实调通过**） |

- **摘档不成立**：30% 独有且是整类别独有（免费与已留源双重不可替），远超"90% 可替才摘"的门槛。
- **保留-仅gap 不成立（两层理由）**：
  1. **面上**：wind 的仅gap 形态是"36 个 API 里留 6 个"；caixin 是 8 个整类 ~200 接口独有，白名单会膨胀成"把源留住"的同义语，失去缩面意义。
  2. **机械上**：`SOURCE_ALLOWED_API_PREFIXES` 按 **api 名前缀**过滤，而 caixin 的 687 接口全走 `caixin_api_call` 一个 api 名（接口选择在 `caixin_call_name` **参数**里）——除非把过滤下沉到参数级（新机制，不值得为此建），否则仅gap 的门根本装不上。
- **留成立**：独有面宽 + 保留零成本 + 数据实调验证通过。

## 3. 使用纪律建议（软路由，非代码门）

1. **行情/基金/宏观/期货/指数类问题一律先走免费**（akshare/统计局/本仓 yahoo/futu），caixin 仅在免费侧失败后兜底 —— 与 wind 裁决第 3 节同款纪律。
2. **caixin 优先场景**：保险（偿付能力/认可资产负债表）、高管人物（履历/学历时序）、环保合规（排污许可/整改）、产业图谱（主题代码表→节点关系→关联公司）、敏感舆情指数、专利、非上市债券发行人财务、银行监管指标。
3. **积分纪律**：多数接口 score=20/次、单次 5 条，翻页按 pageNum 递增逐条扣 —— 调用前先 `caixin_api_search` 确认 score 与 is_free，能用免费接口（如产业链主题代码表 score=0）优先；避免无界翻页。
4. **产业链白名单**：induChaiName/induChaiUniCode 参数必须命中 20 个试用主题（固态电池/半导体/光伏/华为昇腾等，见 describe doc 第 59 行）；先调"主题代码表"拿编码可减少精确匹配失败。
